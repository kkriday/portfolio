CustomerLens

Give it messy customer CSVs. It infers the schema, profiles data quality (nulls, duplicates, per-column stats), cleans the data, and then answers questions about it through a REST API. Every answer cites ticket IDs, so you can check where it came from.

It's built like production code: a pytest suite, ruff + pytest + Docker build in CI, and an LLM backend you can swap that falls back safely when the model call fails.

job: clv_modelmachine learning · regressionidle

Customer lifetime value in auto insurance

How much is a policyholder worth over the whole relationship? I trained five models on 9,134 customers, cross-validated them, and tuned the top two. The result decides how much an insurer can spend to win or keep each customer.

The tuned Random Forest explains 91% of the variance in log CLV. Monthly premium was the strongest driver, which turned into segment-level retention guidance.

About

I started out in mechanical engineering, then moved into software at Accenture. There I built AWS pipelines and tuned SQL for finance and healthcare clients, where bad data has real consequences.

That pulled me into data. At Mercedes-Benz USA I worked on retrieval for a generative-AI Q&A system and on fraud and churn models. At Chubb I migrated enterprise data from SQL Server to Snowflake and built an AI agent that tests MDM and ETL APIs.

The work I like best is where engineering and ML meet: reliable pipelines, tested data, and models whose results you can measure.

A RAG system that answers questions about long corporate reports, with page-level citations. It indexes 815 passages using hybrid BM25 and semantic search merged with Reciprocal Rank Fusion. Answers come from Llama 3.1 running locally, so no data leaves the machine. I evaluated it on 100 hand-built questions.
